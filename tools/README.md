# Helper tools

## CDS Mapper full-scan analysis

`fullscan-analysis-current.zip` contains an offline HTML report generated by CDS Mapper. It is independent of the ABAP and BTP components in this repository.

### Use

1. Extract the archive to a local directory.
2. Open `fullscan-analysis.html` in a modern web browser.
3. Keep the adjacent `fullscan-analysis-data/` directory intact; it contains the report data loaded by the HTML file.

The archive contains 257 files: the report HTML document and 256 JavaScript data files.
